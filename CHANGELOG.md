# BookShelf Project Changelog

Всі ключові зміни, вдосконалення та виправлення проекту BookShelf.

## [v3.3] "The Discovery Hub" — 2026-04-26
### Додано
- **Smarter Randomization**: Книги на головній сторінці та у каруселі тепер рандомізуються при кожному завантаженні для кращого досвіду "відкриття" (Discovery). Порядок залишається стабільним під час фільтрації.

### Виправлено
- **Guest Profile Trigger**: Виправлено помилку, коли іконка профілю не реагувала на натискання для неавторизованих користувачів. Тепер вона коректно перенаправляє на сторінку входу.
- **UI Consistency**: Додано примусове оновлення UI стану при ініціалізації додатку.


## [v3.2] "The Persistent Shelf" — 2026-04-24
### Змінено
- **Database Migration**: Замінено SQLite на **Neon PostgreSQL** (хмарна БД, безкоштовний тариф, постійне збереження).
- **Zero-Downtime Schema**: Міграція тепер використовує `CREATE TABLE IF NOT EXISTS` та `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` — повністю ідемпотентна.
- **Dependency Cleanup**: Видалено `sqlalchemy-libsql`, `libsql` та пов'язані Turso-пакети; замінено на `psycopg2-binary`.

### Виправлено
- **Data Loss on Restart**: Дані користувачів (акаунти, кредити, сесії) тепер зберігаються між рестартами сервера.
- **Email Verification Reliability**: Верифікаційні токени більше не зникають після перезапуску Render.

---

## [v3.1] "The Credit Economy" — 2026-04-23
### Додано
- **Give-to-Get Model**: Впроваджено систему кредитів (1 кредит = 1 завантаження).
- **Incentive System**: Автоматичні бонуси за внески (+5) та підписку на сповіщення (+10).
- **Admin Credit Control**: Можливість адміністраторам вручну коригувати баланс користувачів.
- **Transaction History**: Повний лог змін балансу для користувачів та адмінів.
- **Enhanced Deployment**: Автоматична міграція бази даних та підтримка persistent-дисків Render.

## [v3.0] "The Social Shelf" — 2026-04-21
### Додано
- **User Accounts System**: Повна реєстрація з верифікацією по email та входом на базі JWT.
- **Personal Library Dashboard**: Персональна сторінка користувача з Member ID та списком внесків.
- **Community Contributions**: Можливість користувачам завантажувати власні EPUB файли у бібліотеку.
- **Two-Stage Moderation**: Система пре-модерації внесків через оновлену адмін-панель.
- **Security Suite**: Безпечне збереження паролів (Bcrypt), відновлення доступу та захищені API роути.

## [v2.1] "Glass & Velvet" (`c69dbbc`) — 2026-04-20
### Додано
- **Global Header Entry**: Додано сучасну SVG-іконку профілю у хедер для миттєвого доступу до адмінки.
- **Custom Login Page**: Реалізовано дизайнерську сторінку входу `login.html`, що замінила системні вікна авторизації.
- **Bento Admin Dashboard**: Повний редизайн адмінки з використанням статистичних карток Bento та вкладками навігації.
- **User Voices Feed**: Новий вигляд списку відгуків у форматі стрічки повідомлень із часовими мітками.

### Виправлено
- **Initialization Crash**: Усунуто помилку `ReferenceError` (undefined feedbackTriggerFloating), яка блокувала завантаження книг.
- **Input Styling**: Уніфіковано вигляд усіх текстових полів у додатку (Login, Search, Feedback) под єдиний "Green Velvet" стандарт.

---

## [v2.0] "Emerald Pulse" (`219322c`) — 2026-04-19
### Додано
- **Instagram-Style Search**: Впроваджено повноекранний режим мобільного пошуку з "липким" баром та збереженням результатів.
- **"Green Velvet" Design**: Оновлено дизайн-код додатку (OLED Black, Glassmorphism, Emerald Glow).
- **Bottom Sheet Feedback**: Реалізовано мобільну панель відгуків, що виїжджає знизу з індикатором перетягування (drag handle).
- **Navigation Persistence**: Логіка повернення до результатів пошуку після перегляду деталей книги.

### Виправлено
- **Navigation Loops**: Виправлено рекурсивну помилку в `resetAppView`, яка блокувала кнопку Home.
- **Search Backdrop**: Видалено зайві фонові затемнення, що заважали взаємодії на мобільних.

---

- **Persistent Storage**: Налаштовано збереження бази даних SQLite та EPUB-файлів на постійному диску.

## [v1.0] "Foundations" (`ccc4f5f`) — 2026-04-16
### Додано

- **Responsive Layout**: Початкова підтримка мобільних пристроїв та планшетів.
- **Admin API**: Базовий функціонал завантаження книг та перегляду відгуків.
