# Skill: visual_layout_audit

## Objective
Programmatically verify UI integrity on Mobile and Desktop.

## Instructions
1. **Intersection Test**: Check for any overlapping DOM elements that are not explicitly layered.
2. **Overflow Check**: Fail the test if the page width exceeds the viewport width (No horizontal scroll).
3. **Bilingual Verification**: Verify that Ukrainian text does not "overflow" or break buttons.
4. **Credit Logic Check**: Verify the database deducts exactly 1 credit.
5. **Authorisation**: Empty the input fields before inputting login and password for test user data.
